§01 what's new

The arrow flips

A wave of projects compiles machines into Qwen's weights: a CPU, a GPU, a filesystem, a TPU, a Linux box. In each, Qwen calls the machine. Here the compiled loop calls Qwen.

Related precedents: workflows internalized by fine-tuning (Dennis et al.), compiled modules gated with a pretrained LM (Neural Comprehension), and a compiled oversight monitor inside Qwen (Agrawal). BabyAGI Inside is training-free and runs a whole multi-cycle task loop.

§02 how it works

One cycle, repeated N times

The weights implement the controller and the filesystem. The ledger and results a run produces live in its inference state. Qwen writes only inside the blue boxes; every transition between boxes is compiled.

host.py · the whole runtime

ids = prefill(objective) + [START]
while ids[-1] != HALT:
    ids.append(argmax(model(ids)))

No scheduler, parser, tool executor, retry logic or logits processor. Every prompt, tool call, file response and control symbol after the objective comes from the checkpoint.

2023 → 2026

BabyAGI (2023) was a Python loop around GPT-4: create, prioritize, execute, store. Here what Python did is compiled and what GPT-4 did, Qwen does, in a simplified form: one up-front plan, fixed-order prioritization and a cycle count fixed at build. The checkpoint widens Qwen's residual stream to 4,096 and leaves Qwen's own weights unchanged apart from norm rescaling.

§04 a revealing failure

A wrong plan, executed faithfully

On two eight-cycle structured tasks, the loop did everything it was built to do. The plan Qwen wrote was wrong, and the loop carried it out for eight cycles. Because orchestration is fixed, the failure is visible at the point where it happens.

what the loop did

  • ✓24 of 24 phases, in order
  • ✓Every file write and exact read-back
  • ✓Eight cycles, then HALT
  • ✓Every token accounted to its owner

what qwen planned

  • ✗Task 1 added the combined amount
  • ✗Tasks 2 to 8 each added one
  • ✗0 of 8 transitions correct

The same pattern in both structured traces. Arithmetic chains, where the plan is easy, came out right every time.

§06 scope

What this is, and what it isn't

it is

  • A working prototype of an agent loop compiled into a pretrained model's weights, without training.
  • A checkpoint whose host loop only samples tokens.
  • A way to see exactly which tokens the model wrote, and where it went wrong.

it isn't

  • A smarter Qwen. Capability is still a 2B model's.
  • Unbounded. The cycle count is fixed when the checkpoint is built.
  • Proven for every possible output. Validation covers the tested traces on Apple MPS, bf16.
